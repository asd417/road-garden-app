## 다시 찍으려면

`prototype.html` 주소 끝에 `#demo=1&...`을 붙이면 시뮬레이터 없이 차량 화면만 나옵니다.

- 예: `prototype.html#demo=1&gear=P&eg=0.8&sub=안전운전으로 물방울을 12개 모아서 정원에 줬어요!`
- `eg`: 성장도(0~1), `speed`, `gear`, `charging`, `weather`(맑음·흐림·비·눈), `temp`, `wilt`(0~1), `drops`, `sub`(자막 고정), `bfly=1`(나비 방문), `theme`(꾸미기 배경 0~4), `view=flower`(꽃·잎·나비 모델) + `kind`(꽃 종류 0~3)
